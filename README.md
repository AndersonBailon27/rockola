# Mezcla DJ

Mezcla automática tipo DJ para Android. Subes tus canciones, les das a **Mezclar** y la app hace sola los cambios:

- Detecta el BPM y el golpe de cada canción, iguala la velocidad y cuadra los golpes
- Tres tipos de cambio: cambio de bajos, filtro y eco (automático según el ritmo)
- Iguala el volumen entre canciones y salta los silencios del inicio y del final
- Opciones: duración del cambio, cuánto suena cada canción, ordenar por BPM, repetir lista
- **Grabar mezcla**: la guarda en Música › Mezclas
- Sigue sonando con la pantalla apagada

## Descargar
Ve a **Releases** (a la derecha) y descarga `MezclaDJ.apk`. Cada cambio que se sube a `main` genera una nueva versión automáticamente.
